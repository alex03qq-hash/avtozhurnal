# АвтоЖурнал

Локальное веб-приложение для учёта расходов на автомобиль: заправки, ТО и ремонт, доходы,
поездки, склад запчастей и авто-досье для продажи машины.

Главная идея — **честная стоимость владения**. Приложение показывает не только «сколько я потратил
на бензин», а сколько реально стоит каждый километр с учётом ремонта, страховки, налогов, шин и мойки,
и заранее предупреждает о приближающемся ТО.

Сделано как офлайн-инструмент: все данные лежат в одном файле на вашем компьютере, интернет и аккаунты
не нужны, никакой аналитики и отправки данных наружу.

## Возможности

**Учёт**
- Несколько автомобилей с быстрым переключением в верхней панели.
- Заправки: дата, одометр, объём, цена за литр, сумма (считается автоматически), АЗС, признак «полный бак».
- Расходы по категориям: ТО, ремонт, запчасти, шины и шиномонтаж, страховка, налог, мойка, парковка, штрафы, прочее.
- Доходы (такси, доставка, аренда) и итоговая прибыль.
- Журнал поездок с себестоимостью и прибылью каждой поездки.
- Склад запчастей с артикулами (копирование артикула одной кнопкой) и датами установки.
- Интерактивный чек-лист перед выездом.

**Аналитика**
- Дашборд: расход л/100 км, стоимость километра, траты за месяц и за год, пробег, прибыль.
- Три графика на собственных SVG-компонентах: динамика расхода, траты по месяцам, структура расходов.
- Напоминания о ТО по пробегу и по дате одновременно, с порогами «скоро» и «просрочено».
- Прогноз износа деталей: процент израсходованного ресурса и остаток в километрах и днях.

**Данные и отчёты**
- Авто-досье: отчёт о машине (пробег, вложенные деньги, стоимость километра, история обслуживания,
  состояние по регламентам, запчасти, заправки) с печатью в PDF средствами браузера.
- Экспорт в CSV (с BOM и разделителем `;` — Excel открывает русский текст корректно).
- Полный бэкап в JSON и восстановление в режимах «заменить всё» или «добавить к текущим».
- Демонстрационные данные — два автомобиля и год истории, чтобы сразу увидеть, как всё работает.

**Интерфейс**
- Установка на телефон: приложение ставится на домашний экран, открывается без адресной строки,
  а ссылку на него телефон получает по QR-коду прямо со страницы «Настройки».
- Мобильная вёрстка: нижняя навигация, крупные элементы управления, таблицы превращаются в карточки.
- Работа без сети: оболочка приложения сохраняется в кэш, поэтому оно открывается, даже если
  компьютер с базой выключен (данные при этом, разумеется, недоступны — приложение честно об этом скажет).
- Светлая и тёмная темы (тема «как в системе» учитывает настройку ОС).
- Единицы измерения: километры и литры либо мили и галлоны (в базе данные всегда хранятся в км и литрах).
- Поддержка электромобилей: объём и расход считаются в кВт·ч.
- Полностью на русском языке, без внешних UI-библиотек и шрифтов.

## Требования

- **Node.js 18.18 или новее** (проверено на Node 22). Больше ничего устанавливать не нужно:
  нет нативных модулей, нет Docker, нет базы данных.
- Любой современный браузер (Chrome, Safari, Edge, Firefox).

## Быстрый старт

```bash
# 1. установка зависимостей
npm install

# 2. запуск в режиме разработки (API на :4000, интерфейс на :5173)
npm run dev
```

Откройте http://localhost:5173.

Чтобы сразу увидеть заполненный интерфейс, нажмите на пустом экране **«Загрузить демо-данные»**
или выполните `curl -X POST http://localhost:4000/api/demo`.

```bash
npm start         # сервер на http://localhost:4000 раздаёт и API, и интерфейс
```

## Переменные окружения

Скопируйте `.env.example` в `.env` (или экспортируйте переменные вручную). Секретов приложение не требует.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `4000` | Порт HTTP-сервера. В проде он же отдаёт собранный интерфейс |
| `DATA_DIR` | `./data` | Каталог с файлом базы `db.json` |
| `HOST` | `0.0.0.0` | Интерфейс прослушивания. `0.0.0.0` — доступно и с телефона в той же сети |
| `ACCESS_TOKEN` | — | Код доступа к журналу. Если задан, приложение требует его на телефоне (см. ниже) |
| `HTTPS_KEY` | — | Путь к ключу, если нужен https (см. «Установка на телефон») |
| `HTTPS_CERT` | — | Путь к сертификату для https |
| `NODE_ENV` | `development` | Режим работы (`production` — только информационно) |

## Как считаются показатели

**Расход топлива (л/100 км)** — метод полного бака. Это единственный способ, который даёт корректную
цифру: между двумя заправками «до полного бака» израсходовано ровно столько топлива, сколько залито
во все заправки этого отрезка.

```
расход = Σ объёмов заправок после предыдущей полной (включительно с текущей полной)
         ÷ (одометр текущей полной − одометр предыдущей полной) × 100
```

Если полных заправок меньше двух, приложение честно переключается на упрощённый расчёт
(все залитые литры, кроме первой заправки, на весь пройденный путь) и подписывает это на дашборде.

**Стоимость километра** — `(топливо + все прочие расходы) ÷ пройденный пробег`.
Отдельно показывается стоимость километра только по топливу.

**Износ детали** — `(текущий пробег − пробег последней замены) ÷ ресурс детали × 100 %`.

**Напоминание о ТО** считается и по пробегу, и по дате; берётся более срочный статус.
`просрочено` — остаток ≤ 0, `скоро` — остаток меньше порога предупреждения (по умолчанию 1000 км / 14 дней).

**Единицы.** Внутри базы всё хранится в километрах и литрах. Мили и галлоны — только представление;
перевод выполняется на границе ввода-вывода (`shared/calc.ts` → `client/src/utils/units.ts`).

**Стиль вождения.** Приложение не собирает данные об ускорениях и торможениях, поэтому стиль
определяется косвенно — по отклонению фактического расхода от типовой нормы для этого типа привода
и по интенсивности пробега:

```
множитель износа = 1 + (отклонение расхода от нормы, % / 10) × 0,04   (+0,03 при пробеге > 2500 км/мес)
                    ограничен диапазоном 0,85 … 1,35
норма расхода: бензин 8,5 · дизель 7,0 · газ 10,0 · гибрид 5,5 · электро 17,0 (л или кВт·ч на 100 км)
```

**Прогноз по деталям.** `остаток по пробегу ÷ множитель износа ÷ средний пробег в месяц` = срок в месяцах,
отсюда дата замены. Для просроченных регламентов дата — сегодня.

**Стоимость владения.** Сравниваются стоимость километра сейчас и три месяца назад; рост вместе с
высокими средними тратами даёт подсказку «подумать о продаже». Это **ориентир по вашим собственным
цифрам, а не финансовая рекомендация** — формулировка повторяется и в интерфейсе.

**Округление.** Деньги — до копеек, расход — до одного знака, пробег — до целых. Форматирование
делают общие функции из `shared/format.ts`, поэтому цифры на разных экранах не расходятся.

## API

Все ответы — JSON; ошибки — `{"error": "текст на русском"}`.

| Метод | Адрес | Назначение |
|---|---|---|
| GET | `/api/health` | Состояние сервера, путь к файлу базы |
| GET/PATCH | `/api/settings` | Тема, единицы измерения, активный автомобиль |
| GET/POST | `/api/vehicles`, `/api/fuel`, `/api/expenses`, `/api/incomes`, `/api/trips`, `/api/parts`, `/api/rules`, `/api/checklist` | Список (с фильтром `?vehicleId=`) и создание записи |
| GET/PATCH/DELETE | `/api/<коллекция>/:id` | Чтение, изменение, удаление записи |
| POST | `/api/rules/:id/complete` | Отметить регламент выполненным (проставить текущий пробег и дату) |
| GET | `/api/stats/overview?vehicleId=` | Сводка: расход, ₽/км, траты за месяц и год, прибыль, пробег |
| GET | `/api/stats/consumption?vehicleId=` | Отрезки метода полного бака и точки для графика |
| GET | `/api/stats/monthly?vehicleId=&months=12` | Траты по месяцам |
| GET | `/api/stats/categories?vehicleId=&from=&to=` | Структура расходов по категориям |
| GET | `/api/stats/trips?vehicleId=` | Поездки с расчётной себестоимостью и прибылью |
| GET | `/api/reminders?vehicleId=` | Регламенты ТО со статусами износа |
| GET | `/api/reports/dossier?vehicleId=` | Данные авто-досье |
| GET | `/api/export/csv?vehicleId=&type=fuel\|expenses\|incomes\|all` | Экспорт CSV (BOM + `;`) |
| GET | `/api/export/json?vehicleId=` | Полный бэкап JSON |
| POST | `/api/import/json` | Восстановление: `{"mode":"replace"\|"merge","data":{…}}` |
| POST/DELETE | `/api/demo` | Загрузить демонстрационные данные / удалить все данные |

Примеры:

```bash
curl -X POST http://localhost:4000/api/demo
curl "http://localhost:4000/api/stats/overview"
curl -o zapravki.csv "http://localhost:4000/api/export/csv?type=fuel"
```

## Резервные копии и перенос данных

- **Бэкап:** «Настройки» → «Скачать бэкап JSON» (или `GET /api/export/json`). Файл содержит все записи.
- **Восстановление:** «Настройки» → выберите режим («заменить все данные» или «добавить к текущим»)
  и укажите JSON-файл. Отчёт покажет, сколько записей добавлено.
- **Excel:** «Настройки» → кнопки экспорта CSV. Числа и русский текст открываются корректно.
- Вручную: база — это обычный файл `data/db.json`, его можно просто скопировать.
  При повреждении файла сервер сам сохранит его как `db.json.broken-<время>` и запустится с пустой базой.

## Авто-досье в PDF

Раздел «Авто-досье» → кнопка **«Печать / сохранить в PDF»**. В диалоге печати выберите
«Сохранить как PDF». На печать уходит только содержимое досье: панель управления, меню и кнопки скрыты
правилами `@media print`.

## Установка на телефон

Журнал открывается с телефона в той же сети Wi-Fi, что и компьютер (данные остаются на компьютере,
телефон — это только экран).

```bash
npm run build           # собрать интерфейс
npm start               # сервер напечатает адрес для телефона, например http://192.168.1.42:4000
```

1. Подключите телефон к той же сети Wi-Fi.
2. Откройте «Настройки» → «Установка на телефон»: там виден адрес и QR-код. Наведите камеру телефона
   на QR-код — откроется журнал.
3. Поставьте приложение на домашний экран:
   - **Android/Chrome** — кнопка «Установить приложение» прямо в настройках (браузер сам покажет системное окно);
   - **iPhone/Safari** — «Поделиться» → «На экран „Домой“». В полноэкранном режиме приложение откроется
     сразу, даже без установки через магазин.

### Android и https

Android ставит веб-приложение на домашний экран только по защищённому адресу. Если кнопки установки нет:

```bash
npm run cert            # создаст самоподписанный сертификат для адреса компьютера в сети
npm run start:https     # запустит сервер по https, адрес тоже напечатается
```

Телефон один раз предупредит о самоподписанном сертификате — это ожидаемо, нужно подтвердить переход.
Сертификаты лежат в `.certs/` и в репозиторий не попадают.

### Фото чеков

К заправке и к расходу можно приложить фото чека: кнопка «Приложить фото чека» открывает камеру
телефона (или галерею). Снимок уменьшается прямо в браузере до 1280 точек по длинной стороне,
поэтому база и Wi-Fi не страдают; в списке видна миниатюра, по нажатию фото открывается целиком.
Файлы лежат в `data/photos`, ссылка на фото — в самой записи; при удалении записи фото удаляется вместе
с ней.

При переносе данных копируйте **и** файл базы, **и** папку `data/photos` — JSON-бэкап переносит только
ссылки, сами снимки остаются файлами.

### Быстрые действия с домашнего экрана

Долгое нажатие на иконку установленного приложения даёт четыре действия: **Новая заправка**,
**Чек-лист**, **Обслуживание** и **Авто-досье**. «Новая заправка» открывает форму и сразу ставит курсор
в поле одометра, поэтому запись занимает секунды. Те же действия продублированы крупными кнопками
на дашборде.

### Напоминания о ТО на телефоне

Два пути, оба без сторонних сервисов:

1. **Календарь (основной).** «Настройки» → «Напоминания на телефон» → «Скачать напоминания (.ics)».
   Откройте файл на телефоне — календарь добавит события по каждому регламенту и будет напоминать
   заранее. Для регламентов «по пробегу» дата рассчитывается по вашему среднему пробегу в день;
   просроченные пункты ставятся на сегодня.
2. **Уведомление в приложении.** Кнопка «Включить уведомления» запрашивает разрешение браузера;
   дальше при открытом журнале приходят уведомления о срочных заменах (не чаще одного раза в день).

> Настоящее push-уведомление при **закрытом** приложении требует внешнего push-сервиса и постоянного
> интернета. Для локального журнала это лишняя зависимость, поэтому основной путь — календарь:
> он даёт те же системные напоминания без сторонних сервисов.

Проверка формата: `npm test` (тесты календаря) и `scripts/api-smoke-test.mjs` (структура файла, CRLF, число событий).

### Код доступа к журналу

Пока компьютер и телефон в одной сети Wi-Fi, журнал по умолчанию открыт любому в этой сети.
Защита включается одной строкой:

```bash
# в файле .env (или в переменных окружения)
ACCESS_TOKEN=garage-4821
npm start
```

- На телефоне появится **экран входа**: код запоминается в браузере, повторно вводить его не нужно.
- Требования к коду: латинские буквы, цифры и знаки без пробелов, минимум 6 символов. Кириллицу
  заголовки HTTP не допускают, поэтому сервер откажется запускаться с таким кодом и объяснит причину.
- Снять защиту — удалить переменную `ACCESS_TOKEN` и перезапустить приложение.
- Если код забыт: посмотрите его в `.env` на компьютере либо просто удалите переменную; на телефоне
  выход из журнала — кнопка «Выйти из журнала» в разделе «Настройки».
- Проверка работы: `BASE_URL=http://localhost:4000 ACCESS_TOKEN=ваш-код node scripts/auth-check.mjs`.

## Публикация в GitHub

```bash
GITHUB_TOKEN=ghp_ваш_токен node scripts/publish-to-github.mjs
```

Скрипт создаёт репозиторий `avtozhurnal` (публичный; `GITHUB_PRIVATE=true` — приватный)
и отправляет туда текущую ветку. Нужен персональный токен с правом `repo`
(или fine-grained: *Administration: Read and write* + *Contents: Read and write*).
Токен не сохраняется ни в файлах, ни в `.git/config`.

## Ограничения и что осталось за рамками

- **Нет GPS-трекинга.** Определение поездок по геолокации в браузере требует разрешений и постоянного
  доступа к позиции; в журнал поездки вносятся вручную.
- **Нет карты АЗС и краудсорсинговых цен.** Это требует внешнего сервиса и сетевых запросов,
  что противоречит офлайн-модели приложения.
- **Нет синхронизации между устройствами.** Данные живут в одном файле на компьютере; телефон
  работает как второй экран и требует, чтобы компьютер был включён.
- **Нет авторизации.** Кто угодно в вашей локальной сети может открыть журнал по адресу компьютера.
- **Нет push-уведомлений.** Напоминания видны в интерфейсе; уведомления на телефон не отправляются.
- **Авто-досье — печать средствами браузера.** Отдельный серверный генератор PDF не используется,
  чтобы не тащить в проект тяжёлые зависимости (Chromium/Puppeteer).
- **Одна валюта — российский рубль.** Пересчёт между валютами и смена символа валюты не предусмотрены.
- **Нет авторизации.** Приложение рассчитано на локальный запуск одним человеком.
