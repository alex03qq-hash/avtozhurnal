# Как считаются показатели

Формулы расхода, стоимости километра, износа, стиля вождения и прогнозов.

---

**Расход топлива (л/100 км)** — метод полного бака. Это единственный способ, который даёт корректную
цифру: между двумя заправками «до полного бака» израсходовано ровно столько топлива, сколько залито
во все заправки этого отрезка.

```
расход = Σ объёмов заправок после предыдущей полной (включительно с текущей полной)
         ÷ (одометр текущей полной − одометр предыдущей полной) × 100
```

Если полных заправок меньше двух, приложение честно переключается на упрощённый расчёт
(все залитые литры, кроме первой заправки, на весь пройденный путь) и подписывает это на дашборде.

**Стоимость километра** — `(топливо + все прочие расходы) ÷ пройденный пробег`.
Отдельно показывается стоимость километра только по топливу.

**Износ детали** — `(текущий пробег − пробег последней замены) ÷ ресурс детали × 100 %`.

**Напоминание о ТО** считается и по пробегу, и по дате; берётся более срочный статус.
`просрочено` — остаток ≤ 0, `скоро` — остаток меньше порога предупреждения (по умолчанию 1000 км / 14 дней).

**Единицы.** Внутри базы всё хранится в километрах и литрах. Мили и галлоны — только представление;
перевод выполняется на границе ввода-вывода (`shared/calc.ts` → `client/src/utils/units.ts`).

**Стиль вождения.** Приложение не собирает данные об ускорениях и торможениях, поэтому стиль
определяется косвенно — по отклонению фактического расхода от типовой нормы для этого типа привода
и по интенсивности пробега:

```
множитель износа = 1 + (отклонение расхода от нормы, % / 10) × 0,04   (+0,03 при пробеге > 2500 км/мес)
                    ограничен диапазоном 0,85 … 1,35
норма расхода: бензин 8,5 · дизель 7,0 · газ 10,0 · гибрид 5,5 · электро 17,0 (л или кВт·ч на 100 км)
```

**Прогноз по деталям.** `остаток по пробегу ÷ множитель износа ÷ средний пробег в месяц` = срок в месяцах,
отсюда дата замены. Для просроченных регламентов дата — сегодня.

**Стоимость владения.** Сравниваются стоимость километра сейчас и три месяца назад; рост вместе с
высокими средними тратами даёт подсказку «подумать о продаже». Это **ориентир по вашим собственным
цифрам, а не финансовая рекомендация** — формулировка повторяется и в интерфейсе.

**Округление.** Деньги — до копеек, расход — до одного знака, пробег — до целых. Форматирование
делают общие функции из `shared/format.ts`, поэтому цифры на разных экранах не расходятся.
