# Сметы на ТО

Как посчитать стоимость предстоящей работы по своим данным и превратить её в расход.

---

Перед визитом в сервис можно посчитать, во что обойдётся конкретная работа — по **своим же данным**.

1. «Обслуживание» → у нужного пункта нажмите **«Смета»**.
2. Состав берётся из пакета регламента (что менять), цены — из вашей истории: сначала ищется
   **точное совпадение артикула** в складе запчастей, потом совпадение по названию. Если цены нет —
   приложение честно пишет «впишите сами», а не подставляет среднее по интернету.
3. Укажите часы работ и ставку (по умолчанию 2500 ₽/час, меняется переменной `LABOR_RATE_RUB_PER_HOUR`).
4. **«Сохранить и создать расход»** — смета превращается в обычный расход с расшифровкой, а сама
   остаётся в журнале как источник суммы. Повторное принятие второй расход не создаёт.

Рядом с итогом видно **достоверность**: какая доля цен подтверждена историей. Если цифры вписаны
руками, приложение не делает вид, что это точный расчёт. Смета живёт сутки — цены меняются.

> **Почему без внешних сервисов.** Идея «пусть бот и внешний агент найдут цены» обсуждалась.
> Telegram-бот выносит данные автомобиля во внешний сервис и делает журнал доступным из интернета —
> это противоречит принципу «данные лежат у вас на компьютере». А «поиск цен» через языковую модель
> даёт правдоподобные, но выдуманные суммы: сайты магазинов закрыты от автоматического чтения
> (на регламентах производителей это уже подтвердилось). В бюджете выдуманная цифра хуже честного
> «впишите сами», поэтому цены подсказываются только из вашей истории. Если появится надёжный
> источник цен (например, ваш доступ к API магазина), к смете можно подключить внешнего провайдера —
> интерфейс для этого готов.
