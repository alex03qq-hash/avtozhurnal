# Телефон, доступ и повседневное использование

Установка приложения, код доступа, напоминания, фото чеков и быстрый ввод заправки.

---

Журнал открывается с телефона в той же сети Wi-Fi, что и компьютер (данные остаются на компьютере,
телефон — это только экран).

```bash
npm run build           # собрать интерфейс
npm start               # сервер напечатает адрес для телефона, например http://192.168.1.42:4000
```

1. Подключите телефон к той же сети Wi-Fi.
2. Откройте «Настройки» → «Установка на телефон»: там виден адрес и QR-код. Наведите камеру телефона
   на QR-код — откроется журнал.
3. Поставьте приложение на домашний экран:
   - **Android/Chrome** — кнопка «Установить приложение» прямо в настройках (браузер сам покажет системное окно);
   - **iPhone/Safari** — «Поделиться» → «На экран „Домой“». В полноэкранном режиме приложение откроется
     сразу, даже без установки через магазин.

### Android и https

Android ставит веб-приложение на домашний экран только по защищённому адресу. Если кнопки установки нет:

```bash
npm run cert            # создаст самоподписанный сертификат для адреса компьютера в сети
npm run start:https     # запустит сервер по https, адрес тоже напечатается
```

Телефон один раз предупредит о самоподписанном сертификате — это ожидаемо, нужно подтвердить переход.
Сертификаты лежат в `.certs/` и в репозиторий не попадают.

### Быстрый ввод заправки

На чеке есть два нужных числа — **сумма** и **объём**; цена за литр из них считается сама, и вводить её
не нужно. Так сделано намеренно: расход (л/100 км) считается по объёму, а объём нельзя выводить из средней
цены — на разных АЗС цены разные.

- По умолчанию форма заправки открывается в режиме «Быстро: сумма и объём» (два крупных поля).
- Приложение помнит **цену на каждой конкретной АЗС**: при выборе станции показывает, сколько там было
  в прошлый раз и в среднем.
- Если введена только сумма, приложение подсказывает объём по цене этой АЗС и предлагает его подставить —
  введённый вручную объём всегда главнее подсказки.
- Нужен ввод **только суммы**? Включите галочку «вводить только сумму» — объём подставится по цене
  этой же АЗС. Это осознанный выбор: приложение не выдумывает данные молча, а показывает оценку
  (например, «3 000 ₽ — это ≈ 51,1 л») и требует подтверждения галочкой.
- Режим «Подробно» оставлен для случаев, когда нужно указать цену за литр или тип топлива вручную.

Проверки: `scripts/ui-smoke-test.mjs` (цена считается из суммы и объёма) и `scripts/api-smoke-test.mjs`
(история цен по АЗС, и цены на разных станциях действительно различаются).

### Фото чеков

К заправке и к расходу можно приложить фото чека: кнопка «Приложить фото чека» открывает камеру
телефона (или галерею). Снимок уменьшается прямо в браузере до 1280 точек по длинной стороне,
поэтому база и Wi-Fi не страдают; в списке видна миниатюра, по нажатию фото открывается целиком.
Файлы лежат в `data/photos`, ссылка на фото — в самой записи; при удалении записи фото удаляется вместе
с ней.

**Данные важнее снимка.** Ценность чека — в цифрах, а не в фотографии, поэтому в резервную копию
попадают именно данные: суммы, объёмы и цены, даты, показания одометра, категории и регламенты.
Запись, восстановленная из бэкапа, полностью рабочая и без фото.

Фотографии — это исходники: они лежат отдельными файлами в `data/photos`. Если снимок удалить,
ссылка в записи очистится, а данные останутся нетронутыми (это проверяется скриптом
`scripts/photos-check.mjs`). Чтобы перенести и сами снимки, скопируйте папку `data/photos` вместе
с файлом базы.

### Быстрые действия с домашнего экрана

Долгое нажатие на иконку установленного приложения даёт четыре действия: **Новая заправка**,
**Чек-лист**, **Обслуживание** и **Авто-досье**. «Новая заправка» открывает форму и сразу ставит курсор
в поле одометра, поэтому запись занимает секунды. Те же действия продублированы крупными кнопками
на дашборде.

### Напоминания о ТО на телефоне

Два пути, оба без сторонних сервисов:

1. **Календарь (основной).** «Настройки» → «Напоминания на телефон» → «Скачать напоминания (.ics)».
   Откройте файл на телефоне — календарь добавит события по каждому регламенту и будет напоминать
   заранее. Для регламентов «по пробегу» дата рассчитывается по вашему среднему пробегу в день;
   просроченные пункты ставятся на сегодня.
2. **Уведомление в приложении.** Кнопка «Включить уведомления» запрашивает разрешение браузера;
   дальше при открытом журнале приходят уведомления о срочных заменах (не чаще одного раза в день).

> Настоящее push-уведомление при **закрытом** приложении требует внешнего push-сервиса и постоянного
> интернета. Для локального журнала это лишняя зависимость, поэтому основной путь — календарь:
> он даёт те же системные напоминания без сторонних сервисов.

Проверка формата: `npm test` (тесты календаря) и `scripts/api-smoke-test.mjs` (структура файла, CRLF, число событий).

### Код доступа к журналу

Пока компьютер и телефон в одной сети Wi-Fi, журнал по умолчанию открыт любому в этой сети.
Защита включается одной строкой:

```bash
# в файле .env (или в переменных окружения)
ACCESS_TOKEN=garage-4821
npm start
```

- На телефоне появится **экран входа**: код запоминается в браузере, повторно вводить его не нужно.
- Требования к коду: латинские буквы, цифры и знаки без пробелов, минимум 6 символов. Кириллицу
  заголовки HTTP не допускают, поэтому сервер откажется запускаться с таким кодом и объяснит причину.
- Снять защиту — удалить переменную `ACCESS_TOKEN` и перезапустить приложение.
- Если код забыт: посмотрите его в `.env` на компьютере либо просто удалите переменную; на телефоне
  выход из журнала — кнопка «Выйти из журнала» в разделе «Настройки».
- Проверка работы: `BASE_URL=http://localhost:4000 ACCESS_TOKEN=ваш-код node scripts/auth-check.mjs`.
